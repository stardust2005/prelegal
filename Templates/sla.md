# Acuerdo de Nivel de Servicio

1. <span class="header_2" id="1">Disponibilidad</span>
    1. <span class="header_3" id="1.1">Disponibilidad Objetivo.</span>  Si existe una <span class="orderform_link">Disponibilidad Objetivo</span>, <span class="coverpage_link">Proveedor</span> realizará esfuerzos comercialmente razonables para que el Servicio en la Nube esté disponible al menos durante la <span class="orderform_link">Disponibilidad Objetivo</span>, calculada cada mes calendario.
    2. <span class="header_3" id="1.2">Cálculo de la Disponibilidad.</span>  <span class="coverpage_link">Proveedor</span> y <span class="coverpage_link">Cliente</span> acuerdan calcular la disponibilidad del Servicio en la Nube como el número total de Minutos Disponibles menos el número de Minutos de Inactividad, dividido entre el número total de Minutos Disponibles, medido en un mes calendario. Si el <span class="orderform_link">Período de Suscripción</span> incluye un mes parcial, el numerador y el denominador solo incluirán los días que formen parte del <span class="orderform_link">Período de Suscripción</span> para ese mes.

2. <span class="header_2" id="2">Tiempo de Respuesta</span>
    1. <span class="header_3" id="2.1">Tiempo de Respuesta Objetivo.</span> Si existe un <span class="orderform_link">Tiempo de Respuesta Objetivo</span>, <span class="coverpage_link">Proveedor</span> realizará esfuerzos comercialmente razonables para responder a las solicitudes de soporte enviadas al <span class="orderform_link">Canal de Soporte</span> dentro del <span class="orderform_link">Tiempo de Respuesta Objetivo</span>.
    2. <span class="header_3" id="2.2">Cálculo del Tiempo de Respuesta.</span>  <span class="coverpage_link">Proveedor</span> y <span class="coverpage_link">Cliente</span> acuerdan calcular el tiempo de respuesta de <span class="coverpage_link">Proveedor</span> como el tiempo total transcurrido entre el momento en que <span class="coverpage_link">Cliente</span> envía una solicitud de soporte al <span class="orderform_link">Canal de Soporte</span> y el momento en que <span class="coverpage_link">Proveedor</span> o el representante de soporte de <span class="coverpage_link">Proveedor</span> reconoce específicamente la solicitud. Una respuesta automatizada no constituye un reconocimiento específico a los efectos de este SLA.

3. <span class="header_2" id="3">Remedios</span>
    1. <span class="header_3" id="3.1">Crédito de Servicio.</span>  Si existe una <span class="orderform_link">Disponibilidad Objetivo</span> y la disponibilidad del Servicio en la Nube cae por debajo de la <span class="orderform_link">Disponibilidad Objetivo</span>, <span class="coverpage_link">Cliente</span> tiene derecho a recibir un <span class="orderform_link">Crédito de Disponibilidad</span>. Si existe un <span class="orderform_link">Tiempo de Respuesta Objetivo</span> y ni <span class="coverpage_link">Proveedor</span> ni el representante de soporte de <span class="coverpage_link">Proveedor</span> reconocen una solicitud de soporte enviada al <span class="orderform_link">Canal de Soporte</span> dentro del <span class="orderform_link">Tiempo de Respuesta Objetivo</span>, <span class="coverpage_link">Cliente</span> tiene derecho a recibir un <span class="orderform_link">Crédito de Tiempo de Respuesta</span>. Los Créditos de Servicio solo se aplican a futuras Tarifas del Servicio en la Nube que <span class="coverpage_link">Cliente</span> adeude a <span class="coverpage_link">Proveedor</span>.
    2. <span class="header_3" id="3.2">Solicitud de un Crédito de Servicio.</span>  Para recibir un Crédito de Servicio, <span class="coverpage_link">Cliente</span> debe notificar a <span class="coverpage_link">Proveedor</span> dentro de los 7 días posteriores al final del mes en el que <span class="coverpage_link">Cliente</span> considere que se generó el Crédito de Servicio; de lo contrario, el derecho al Crédito de Servicio expirará para ese mes.
        a. Para el <span class="orderform_link" id="3.2.a">Crédito de Disponibilidad</span>, <span class="coverpage_link">Cliente</span> debe incluir información sobre cuándo no pudo acceder al Servicio en la Nube. Es posible que se solicite a <span class="coverpage_link">Cliente</span> que proporcione detalles adicionales sobre sus intentos de acceder al Servicio en la Nube. Si <span class="coverpage_link">Proveedor</span> puede verificar la indisponibilidad del Servicio en la Nube en sus sistemas internos de monitoreo y la interrupción no califica como Minutos Excluidos o <span class="orderform_link">Inactividad Programada</span>, <span class="coverpage_link">Proveedor</span> calculará y emitirá el <span class="orderform_link">Crédito de Disponibilidad</span> aplicable en la cuenta de <span class="coverpage_link">Cliente</span> para aplicarlo a una futura factura.
        b. Para el <span class="orderform_link" id="3.2.b">Crédito de Tiempo de Respuesta</span>, <span class="coverpage_link">Cliente</span> debe incluir información sobre cuándo y cómo <span class="coverpage_link">Cliente</span> contactó a <span class="coverpage_link">Proveedor</span>. Es posible que se solicite a <span class="coverpage_link">Cliente</span> que proporcione detalles adicionales sobre el incidente relacionado y sus intentos de recibir soporte. Si <span class="coverpage_link">Proveedor</span> puede verificar que ni <span class="coverpage_link">Proveedor</span> ni el representante de soporte de <span class="coverpage_link">Proveedor</span> respondieron a la solicitud de soporte de <span class="coverpage_link">Cliente</span> dentro del <span class="orderform_link">Tiempo de Respuesta Objetivo</span>, <span class="coverpage_link">Proveedor</span> calculará y emitirá el <span class="orderform_link">Crédito de Tiempo de Respuesta</span> aplicable en la cuenta de <span class="coverpage_link">Cliente</span> para aplicarlo a una futura factura.
    3. <span class="header_3" id="3.3">Limitaciones de los Créditos de Servicio.</span>  Los Créditos de Servicio no pueden intercambiarse ni convertirse en importes monetarios. Los Créditos de Servicio no generan intereses. Los Créditos de Servicio no se acumularán dentro de un único <span class="orderform_link">Período de Suscripción</span> en un importe superior al 8% de las Tarifas del Servicio en la Nube correspondientes a dicho <span class="orderform_link">Período de Suscripción</span>. Los Créditos de Servicio expiran cuando finaliza el Formulario de Pedido correspondiente.
    4. <span class="header_3" id="3.4">Terminación.</span>  Si el Servicio en la Nube no alcanza la <span class="orderform_link">Disponibilidad Objetivo</span> durante dos (2) de cualesquiera tres (3) meses consecutivos y <span class="coverpage_link">Cliente</span> notificó a <span class="coverpage_link">Proveedor</span> de los incumplimientos dentro de los 7 días posteriores al final de cada mes afectado, <span class="coverpage_link">Cliente</span> podrá terminar de inmediato el Formulario de Pedido afectado mediante notificación escrita a <span class="coverpage_link">Proveedor</span>. Si <span class="coverpage_link">Cliente</span> termina un Formulario de Pedido conforme a esta sección, <span class="coverpage_link">Proveedor</span> pagará a <span class="coverpage_link">Cliente</span> un reembolso prorrateado de las tarifas prepagadas por el resto del <span class="orderform_link">Período de Suscripción</span>.
    5. <span class="header_3" id="3.5">Remedio Exclusivo.</span>  Este SLA describe el remedio exclusivo de <span class="coverpage_link">Cliente</span> y la responsabilidad íntegra de <span class="coverpage_link">Proveedor</span> ante cualquier incumplimiento del Servicio en la Nube respecto de la <span class="orderform_link">Disponibilidad Objetivo</span> y ante cualquier incapacidad de cumplir el <span class="orderform_link">Tiempo de Respuesta Objetivo</span>.

4. <span class="header_2" id="4">Definiciones</span>
    1. <span id="4.1">**"Minutos Disponibles"**</span>  significa el número total de minutos en un mes calendario, menos los Minutos Excluidos y la <span class="orderform_link">Inactividad Programada</span>.
    2. <span id="4.2">**"Minutos de Inactividad"**</span> significa el número total de minutos en un mes calendario durante los cuales el Servicio en la Nube no está disponible para <span class="coverpage_link">Cliente</span>, según lo confirmen los sistemas internos de monitoreo de <span class="coverpage_link">Proveedor</span>, menos los Minutos Excluidos y la <span class="orderform_link">Inactividad Programada</span>.
    3. <span id="4.3">**"Minutos Excluidos"**</span> significa cuando el Servicio en la Nube no está disponible debido a (a) un Evento de Fuerza Mayor; (b) problemas generales de conectividad a Internet; (c) equipos o software puestos a disposición por alguien distinto de <span class="coverpage_link">Proveedor</span> y que no esté bajo el control razonable de <span class="coverpage_link">Proveedor</span>; o (d) el uso del Servicio en la Nube por parte de <span class="coverpage_link">Cliente</span> de una forma no autorizada por el Acuerdo.
    4. <span id="4.4">**"Crédito de Servicio"**</span> significa el <span class="orderform_link">Crédito de Disponibilidad</span> acumulado más el <span class="orderform_link">Crédito de Tiempo de Respuesta</span> acumulado.
    5. <span id="4.5">**"SLA"**</span> significa estos Términos Estándar del SLA tal como se incorporan al Formulario de Pedido correspondiente.
    6. <span id="4.6">**"Términos Estándar del SLA"**</span> significa estos Términos Estándar del Acuerdo de Nivel de Servicio de Common Paper, Versión 2.0, publicados en <https://commonpaper.com/standards/service-level-agreement/2.0/>.
