# prelegal
Una plataforma para redactar acuerdos legales comunes

> **Estado del proyecto:** En progreso. Se estima que estará completado en una semana.

## Desarrollo

```bash
scripts/start-mac.sh    # Mac: levanta el contenedor Docker
scripts/stop-mac.sh     # Mac: lo detiene

scripts/start-linux.sh  # Linux
scripts/stop-linux.sh

scripts/start-windows.ps1  # Windows
scripts/stop-windows.ps1
```

Backend disponible en http://localhost:8000.
